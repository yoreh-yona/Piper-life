# החיים של פייפר

יומן צבעוני לילדים למעקב אחרי פייפר, פיתונית מתכדררת: ארוחות, השלות עור, ניקיון, יומן, אלבום תמונות ולוח שנה.

## התקנה באנדרואיד
1. בטלפון נכנסים לדף **Releases** של המאגר (בצד ימין של דף המאגר, או `github.com/yoreh-yona/Piper-life/releases/latest`).
2. מורידים את `piper-life.apk`.
3. פותחים את הקובץ. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקורות לא ידועים" עבור הדפדפן.
4. גרסה חדשה מתקינים באותה דרך, והיא נכנסת מעל הישנה בלי למחוק נתונים.

## התקנה באייפון
1. ב־Safari נכנסים ל־`https://yoreh-yona.github.io/Piper-life/`
2. לוחצים על כפתור השיתוף ובוחרים **הוסף למסך הבית**.

## גיבוי
כל הנתונים נשמרים בטלפון עצמו. בתחתית האפליקציה יש **שמור גיבוי** ו**טען גיבוי**.

## איך זה בנוי
- `www/` — האפליקציה (קובץ HTML אחד, גופנים ואייקונים).
- `.github/workflows/android.yml` — בונה APK עם Capacitor בכל עדכון ומפרסם אותו ב־Releases.
- `.github/workflows/pages.yml` — מפרסם את `www/` ב־GitHub Pages לאייפון.
- `android-signing/debug.keystore` — מפתח החתימה של האפליקציה. הוא נשמר במאגר כדי שכל גרסה חדשה תותקן מעל הקודמת.
